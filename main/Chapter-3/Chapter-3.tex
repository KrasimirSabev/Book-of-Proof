\part{Counting}

At its most basic level, counting is the process of poinitng to each object in a collection and calling out the consecutive numerical values until there are no more items to count. 

The goal of this chapter is to answer the question `How many?' by introducing mathematical techniques that bypass the actual process of counting individual objects.
